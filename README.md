# 🎓 Student Performance Analytics & Predictive Insights Dashboard

## 📊 Overview

This project is an interactive Excel dashboard designed to analyze student academic performance and provide predictive insights using a simple machine learning approach.

The dashboard combines:

* Descriptive analytics (what happened)
* Diagnostic insights (why it happened)
* Predictive modeling (what is likely to happen)

---

## 🎯 Objectives

* Analyze key drivers of student performance
* Identify relationships between study behavior and outcomes
* Predict at-risk students using a scoring model
* Deliver an interactive, executive-level dashboard

---

## 🧰 Tools Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Slicers (interactive filtering)
* Excel Formulas (IF, IFS, AVERAGE, COUNTIF)

---

## 📈 Key Features

### 🔹 KPI Dashboard

* Average Final Exam Score
* Pass Rate
* Average Study Hours
* Average Attendance

### 🔹 Interactive Visuals

* Performance by Gender
* Study Hours vs Exam Score
* Attendance vs Performance (Scatter Analysis)
* Income vs Academic Performance

### 🔹 Predictive Analytics (ML Feature)

* Model Score based on:

  * Study Hours
  * Attendance
  * Previous GPA
  * Assignment Completion
* Risk Segmentation:

  * High Risk
  * Medium Risk
  * Low Risk

---

## 🧠 Key Insights

* Study hours and attendance are the strongest predictors of performance
* Higher attendance correlates with higher exam scores
* Socioeconomic factors influence outcomes moderately
* A segment of students is identified as "at risk"

---

## 💡 Recommendations

* Implement early intervention for high-risk students
* Encourage structured study routines
* Improve attendance monitoring
* Provide support to lower-income student groups
